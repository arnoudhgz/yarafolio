# Contributing to YaraFolio

Thank you for your interest in contributing to YaraFolio! As this is primarily my personal stock portfolio helper, there are some specific guidelines on what types of contributions are helpful and what will likely be rejected.

## What is Welcome

*   **Bug Fixes:** Pull Requests (PRs) that fix clear, reproducible bugs in the existing Python scripts or frontend code are welcome and appreciated.
*   **Feature Requests & Suggestions:** Feel free to open an issue to suggest a new feature or improvement. I'm always open to ideas that enhance the core functionality!

## What is NOT Welcome (Will be closed)

*   **Changes to AI Skills / Strategy:** The AI prompts, skills (e.g., in `GEMINI.md` or `.claude/`), and trading strategy parameters are highly tailored to my personal preferences and trading style. PRs attempting to change these will not be accepted.
*   **Heavy Tooling / Compilers:** PRs that introduce heavy tooling, JS compilers, or complex build steps will not be handled and will be closed. The goal is to keep the stack as simple as possible.
*   **Mobile Views / Layout Overhauls:** The dashboard UI is designed specifically for my personal desktop usage. PRs attempting to introduce responsive mobile views or completely redesign the layout will be closed.

## How to Submit a Bug Fix

1.  Fork the repository.
2.  Create a new branch for your fix.
3.  Ensure your code follows the existing style (we use PEP8 for Python).
4.  Submit a Pull Request with a clear description of the bug and how your code fixes it.

Thank you!
