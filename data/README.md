# Advice log data

`advice-log.json` is the source of truth for `dashboard.html`. Updated by `/advice`, `/premarket`, `/check`, `/import` and by the dashboard buttons (via `yarafolio.py`: `/api/save`, `/api/import`, `/api/refresh`; `/api/stats` reads `review_stats.py`).

**Skills never hand-edit these JSON files.** All log mutations go through `scripts/advice_log.py` (add-pick, add-note, touch, touch-many, set-status, set-tsl, checkin-candidates, compare, sector-gaps). `touch-many` reads a `{"TICKER": price}` map on stdin and is how the dashboard's "Refresh quotes" button writes scraped prices back (yarafolio.py runs `screen.py quote --json` then pipes it to `touch-many`, so the web layer never touches the JSON). Stats come from `scripts/review_stats.py`. Portfolio sync via `scripts/etoro_import.py`. Mechanical market data (oversold screen, quote stats) via `scripts/screen.py`.

Entry shape:

```json
{
  "ticker": "SBUX",
  "name": "Starbucks",
  "firstAdvised": "2026-06-12",
  "source": "advice | premarket | import | diversify",
  "rating": "B+",
  "rsiAtAdvice": 27,
  "priceAtAdvice": 81.20,
  "reason": "short thesis",
  "risk": "short risk note",
  "sector": "Services",
  "buyBelow": 78.50,
  "dropBelow": 72.00,
  "dropAbove": 92.00,
  "status": "watching | bought | sold | dropped",
  "boughtAt": null,
  "soldAt": null,
  "units": null,
  "droppedDate": null,
  "lots": [{ "positionID": 123, "openDate": "2026-06-15", "openRate": 79.10, "units": 7.4,
             "lastPrice": 85.0, "tslEnabled": false, "soldAt": null, "exitEstimated": false }],
  "priceHistory": [{ "date": "2026-06-12", "price": 81.20 }],
  "notes": [{ "date": "2026-06-12", "text": "Advised (advice): tariff overreaction, Q2 was strong" }]
}
```

- `sector`: one of eToro's 9 industries (Basic Materials, Conglomerates, Consumer Goods, Financial, Healthcare, Industrial Goods, Services, Technology, Utilities) or `"ETF / Other"`. Null when unknown. ETFs always get `"ETF / Other"` (eToro tags them with a bogus Financial industry, the import corrects that via instrumentTypeID).
- `buyBelow` / `dropBelow` / `dropAbove`: tipping points, generated by advice/check runs only. Entry trigger / thesis-invalidation floor / opportunity-gone ceiling (above `dropAbove` the oversold bounce already ran, so a still-watched pick is worth dropping; only meaningful while `watching`). The dashboard highlights when the price crosses them, no manual editing.
- `lots`: the per-position ledger for advice picks, owned by the eToro import. Each lot is one eToro position **opened on/after `firstAdvised`** (and before `droppedDate`); lots held before the advice, or opened after dropping it, are NOT attributed (they stay plain holdings on the Portfolio tab). Per lot: `positionID` (eToro's, used to detect closes across imports), `openDate`, `openRate`, `units`, `lastPrice` (refreshed each import), `tslEnabled`, `soldAt` (null = open), `exitEstimated`. When a lot's `positionID` disappears from eToro it's auto-closed at `lastPrice` with `exitEstimated: true` (eToro has no exit price); the Positions tab "Needs confirm" filter and the check-in surface those, and the dashboard Confirm / `set-status sold --price` sets the real exit. The Positions tab + win rate / realized money are computed **per lot** from this array.
- `boughtAt` / `units` / `soldAt` / `status` / `exitEstimated`: a **rollup recomputed from `lots`** by the import (so `learn_stats` and the % math keep working): `boughtAt` = units-weighted avg openRate, `units` = sum of open-lot units, `status` = bought if any open lot else sold, `soldAt` = weighted avg exit once all closed. A pick with no attributed lots keeps its watchlist state.
- `droppedDate` (optional): set by `set-status dropped`; lots opened on/after it aren't the advice's trade.
- `priceHistory`: one point per run/update, powers the sparklines.
- `notes`: dated commentary history (news, what happened, verdicts), appended chronologically, shown newest-first in the drill-down. Written via `advice_log.py add-note` or the `--note` flag on `add-pick`; `set-status`/`set-tsl` and the auto-close append automatic notes. First advise auto-notes the reason.
- `tslSet` (optional, true): trailing stop loss is active on eToro. The import sets it from the position's `isTslEnabled`, so it reflects eToro reality; a true value keeps the ticker out of the +5% check-in (the eToro sync catches the exit when the stop fires).

## portfolio.json

Full eToro holdings snapshot, written by `scripts/etoro_import.py merge` on every sync. Generated, never hand-edit. Read by the dashboard Portfolio tab and by `/diversify` (sector gaps).

```json
{
  "lastUpdated": "2026-06-12",
  "totalInvested": 42261.94,
  "holdings": [{
    "ticker": "GOOG", "name": "Alphabet", "instrumentID": 1002,
    "sector": "Technology", "positions": 1, "units": 1.681425,
    "invested": 599.97, "avgOpen": 356.82, "currentPrice": 359.86,
    "plDollar": 5.11, "plPct": 0.85, "firstOpen": "2026-06-04"
  }]
}
```

## instruments.json

Cache mapping eToro instrument IDs to `{ticker, name, sector}`. Merged (never truncated) on every preview so sold instruments keep their sector data for backfills.
